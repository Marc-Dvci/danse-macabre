# Rules for every session

- Never delete files, commit, push, or change GitHub. Report files that should go and the owner removes them.
- Never edit `.kiro/agents`, `.kiro/hooks`, `.kiro/steering` or `.kiro/settings`. Ask in the final report instead.
- State only what was done and measured. Every number in a report or a document must come from a command you ran.
- Describe data by where it comes from: a CMU subject and trial, a reference video, or a generator. Generated test
  inputs are "generated scores" or "property-test inputs".
- Motion data comes from the CMU Graphics Lab Motion Capture Database (free for all uses, no resale). Name the source
  and the subject/trial number of every clip.
- End every session with a report: STATUS, DONE (with test counts), DECISIONS I MADE, NOT TRUE YET, QUESTIONS, NEXT.
